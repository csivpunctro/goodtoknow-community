# GoodToKnow Community 🌱

[Română](#română) | [English](#english)

## Română

Bine ai venit în spațiul public de colaborare GoodToKnow.ro.

GoodToKnow este o comunitate generalistă în română și engleză, dedicată întrebărilor, experiențelor, recomandărilor și explicațiilor utile.

Aici poți contribui la **îmbunătățirea platformei**: idei, sugestii de design, raportări de erori, propuneri de accesibilitate, traduceri și raportări de probleme.

- **Discussions:** idei, întrebări despre evoluția produsului și sondaje.
- **Issues:** erori reproductibile și sarcini acceptate.
- **Pull requests:** texte, traduceri, ghiduri sau alte fișiere publice ale acestui repository.

Codul aplicației GoodToKnow.ro se află într-un repository privat separat. Acest repository public **nu conține codul aplicației, date ale utilizatorilor sau informații de infrastructură**.

Propunerile nu sunt aprobate automat. Echipa verifică impactul, siguranța, licențele și prioritatea. Un vot nu declanșează un deployment.

Nu publica parole, tokenuri, date personale, configurații interne sau vulnerabilități de securitate. Citește [SECURITY.md](SECURITY.md) și [CONTRIBUTING.md](CONTRIBUTING.md).

## English

Welcome to the public GoodToKnow.ro collaboration space.

GoodToKnow is a general-interest Romanian and English community for practical questions, experiences, recommendations, and explanations.

You can help **improve the platform** with ideas, design suggestions, bug reports, accessibility improvements, translations, and issue reports.

- **Discussions:** ideas, product discussions, and polls.
- **Issues:** reproducible bugs and accepted work items.
- **Pull requests:** public documentation, translations, guides, and other files in this repository.

The GoodToKnow application source code lives in a separate private repository. This public repository **does not contain application code, member data, or infrastructure information**.

Suggestions are reviewed by the team. Votes inform priorities but never trigger a deployment.

Do not share passwords, tokens, personal data, internal configurations, or security vulnerabilities. Read [SECURITY.md](SECURITY.md) and [CONTRIBUTING.md](CONTRIBUTING.md).
