# Contribute / Contribuie

## Română

1. Caută mai întâi dacă ideea sau problema există deja.
2. Pentru idei, folosește Discussions. Pentru erori reproductibile, completează formularul Issue.
3. Explică ce problemă rezolvi, pentru cine și cum ai verifica rezultatul.
4. Nu include date personale, chei de acces, capturi cu informații private ori vulnerabilități.
5. Respectă limbile RO și EN. Pentru o traducere, precizează pagina și pasajul afectat.
6. Propunerile sunt analizate; aprobarea, prioritizarea și deploymentul aparțin echipei GoodToKnow.
7. Pentru modificările publice ale acestui repository, deschide un pull request cu explicația schimbării. Nu există acces la codul privat.

Contribuțiile acceptate pot fi creditate în changelog cu acordul autorului. Nu promitem XP, badge-uri, premii sau compensații până la publicarea regulilor relevante.

## English

1. Search existing ideas and bug reports first.
2. Use Discussions for ideas and the Issue form for reproducible bugs.
3. Explain the user problem, who benefits, and how the result can be tested.
4. Never include personal information, credentials, private screenshots, or security vulnerabilities.
5. Specify the affected page and language for translation proposals.
6. All suggestions are reviewed. Product decisions and deployments remain with the GoodToKnow team.
7. Public-repository document changes can be submitted by pull request. The private application source is not exposed.

Accepted work may be credited in the changelog with the contributor's consent. XP, badges, prizes, and compensation require separately published rules.
